🚀 Built and deployed a POSH Policy Chatbot for Asian Paints using AWS Bedrock during my intership at Innomatics Research Labs under the guidance of Yasoda Sreeram Kalluri, Sir.

Excited to share my recent project where I developed a Retrieval-Augmented Generation (RAG) chatbot to answer queries related to the POSH (Prevention of Sexual Harassment) policy for Asian Paints — and deployed it on the cloud 🚀

💡 The system enables users to ask natural language questions and receive accurate, context-aware answers directly from policy documents.

🔧 Tech Stack:
• Python
• Streamlit (UI)
• AWS Bedrock (Knowledge Base)
• Boto3
• Amazon S3 (for storing policy documents)
• Amazon Nova Lite v1
• Amazon EC2 (deployment)

✨ Key Features:
✔ Policy documents securely stored in S3 bucket
✔ Intelligent retrieval using Bedrock Knowledge Base
✔ Context-aware responses powered by LLM
✔ Deployed on EC2 instance for real-time access
✔ Simple and interactive UI with Streamlit

📌 Key Learnings:
• Building end-to-end RAG pipelines
• Integrating S3 with Bedrock Knowledge Base
• Deploying RAG application on EC2
• Working with LLMs in real-world enterprise use cases
